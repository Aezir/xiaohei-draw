仓库按令牌自动识别

把画廊里全部的图（包括网站自带的）、收藏、合集、分支、分组，按数据仓库的格式在本机加密，打成一个 zip。 适合一次放进大量图：网页上传每小时只能创建几百个文件，包可以用 git 一次推进仓库。

令牌怎么拿？数据安全吗？

令牌在 GitHub → Settings → Developer settings → Fine-grained tokens 里生成：Repository access 只选数据仓库， Permissions 里 Contents 设为 Read and write。令牌和由密码算出的密钥只存在这台设备的浏览器，不进导出的配置。

仓库里的数据在浏览器里先加密再上传，GitHub 上只看得到乱码；忘了密码就解不开，没有找回。 别的设备同步时只先下缩略图，大图点开才下。

本地备份

同步要改本机数据前、每天第一次打开时各存一份，保留最近 8 份。 恢复是「合并回来」：备份里有、现在没了的会加回来，现在新加的保留。
